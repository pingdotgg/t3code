# Only a structured signal may complete a Goal

Auto-continue needs an end other than Stop. Trusting assistant prose would false-complete. Requiring a user to confirm every completion would turn a Goal back into babysitting.

We decided a Turn may complete a Goal only via a structured signal, the same kind of typed artifact T3 already uses for proposed plans. The user may also complete or clear by hand. Saying “done” in chat is not Complete.
