# An Active Goal outlives the client

Settle, Snooze, and a closed window could have been treated as Stop. That would make a Goal just a loud Turn: work dies when you look away.

We decided an Active Goal keeps working on the server. Settle, Snooze, and disconnected clients do not Pause. Stop, explicit Pause, Complete, and Clear still do. The session reaper must treat an Active Goal as live work, not idle.
