# The first Goal Turn is a real user message

`/goal` must not be forwarded as provider slash text — Codex would then own a native goal T3 cannot see. Continuations also have no user message.

The first Turn is different: the user did speak. We decided that sending `/goal Reduce p95 below 120ms` on an idle Thread records `Reduce p95 below 120ms` as a normal user message and starts that Turn on it. The `/goal` prefix is intercept-only. Later Continuations stay message-less.
