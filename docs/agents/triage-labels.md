# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for clarification |
| `ready-for-agent` | `ready-for-agent` | Fully specified work an agent can implement |
| `ready-for-human` | `ready-for-human` | Work requires human implementation |
| `wontfix` | `wontfix` | Work will not be actioned |

These are the default Matt Pocock skill labels. Configuration records the names;
it does not create remote labels or issues.
