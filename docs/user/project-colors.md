# Project colors

Assign a color to a project to tell repos apart at a glance. The color shows as a small dot next
to the project wherever it appears: on thread rows and cards in the sidebar, in the project filter
menu, and in the chat header.

To set a color, open the sidebar's project filter menu, click the **⋯** button next to the
project, and pick a swatch under **Color**. Choose the crossed-out swatch to remove the color.
The color is stored by the server and appears on your other connected devices. Projects grouped
as one repo share a single color: setting it in any environment colors the whole group.

If the color picker is missing for one environment, update the T3 Code server running in that
environment. Older servers do not understand project colors and keep working without them.
