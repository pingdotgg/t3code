# Skills in threads

When you call an available skill in a message, its `$skill-name` appears as a clickable chip in the thread. Select the chip to open that skill's current `SKILL.md` in the right-panel file viewer.

Skill files are read-only in T3 Code. You can switch between rendered Markdown and source views. Links and images inside the skill folder also open in the file viewer.

If a skill is removed after you call it, the original chip stays in the thread and the viewer explains that the file is no longer available.
