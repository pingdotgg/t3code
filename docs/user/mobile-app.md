# Mobile app

Use the native T3 Code app to connect to your environments, control coding agents, and follow agent
activity from a phone or tablet.

- [Download for iPhone and iPad on the App Store](https://apps.apple.com/us/app/t3-code-remote-claude-more/id6787819824)
- [Get the Android app on Google Play](https://play.google.com/store/apps/details?id=com.t3tools.t3code&pli=1)

The mobile app is a client: a T3 Code server must still be running on the machine that owns your
projects and agent sessions. For pairing and network setup, see [Remote Access](./remote-access.md).
