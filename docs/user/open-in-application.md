# Open a project in another application

The **Open** menu lists the editors T3 Code finds installed on the machine that runs your
environment. If the tool you want is not on that list, choose it yourself.

1. Select the arrow next to **Open**.
2. Select **Open with…**.
3. Search the list and select an application.

T3 Code opens the project folder in that application and makes it your default for the **Open**
button, so next time it is one click. A check mark in the list marks applications already in the
menu.

To take an application back out of the menu, open **Open with…** again and select the ✕ next to it.

## Things to know

The list comes from the applications installed on the machine hosting your environment, not the
machine you are looking at. That is the machine that actually runs the program, so the list is the
same whether you are on the desktop app or connected from a browser or phone.

An application stays in the **Open** menu only while T3 Code can still find it. If you uninstall the
program, its entry disappears from the menu and comes back on its own if you reinstall it. To drop
it for good, remove it from the **Open with…** list.

**Open with…** does not appear when you are connected to a remote environment over SSH links. That
mode can only use editors that know how to open a workspace remotely.
