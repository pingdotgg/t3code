# Open a project in another application

The **Open** menu lists the editors T3 Code finds on the machine running your environment. For
anything else, select the arrow next to **Open**, choose **Open with…**, then search and pick.

The list comes from the machine hosting your environment, not the one in front of you, so it is the
same from the desktop app, a browser, or a phone. **Open with…** appears on Linux hosts; elsewhere,
and over SSH links, the **Open** menu still lists every editor T3 Code detects.
