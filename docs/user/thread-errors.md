# Thread errors

When a provider or its process fails, T3 Code shows an error banner above the thread on web and
desktop. Select the copy button to copy the complete diagnostic, including text that is visually
truncated in the banner. If the browser or operating system blocks clipboard access, T3 Code shows
a failure message instead of copied feedback.

Select the × button to dismiss the current error. Dismissing it hides that diagnostic for the rest
of the current app session; it does not delete the provider's recorded error. A different error on
the same thread will appear normally.
