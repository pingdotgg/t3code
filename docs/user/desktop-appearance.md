# Desktop appearance

T3 Code Desktop can follow the active [Omarchy](https://omarchy.org/) color theme.

When Omarchy's generated VS Code palette is available, **Omarchy Linked** appears in **Settings → Appearance → Themes**. Select it once and T3 Code updates automatically when you switch Omarchy themes. Selecting any other T3 Code theme stops following Omarchy.

The card is only shown in T3 Code Desktop on an Omarchy system. There is no file picker or setup step.
