# Review a proposed plan

When an agent publishes a proposed plan in the web or desktop app, select **Review plan** on the plan card to have another agent critique it in a separate background thread.

Choose the reviewing agent for that run, then start the review. The reviewer receives the complete plan and repository context, but is instructed not to make changes or implement the plan. You can continue working in the original thread while it runs.

When the review settles, the plan card lets you:

- **Open review** to read the full review thread.
- **Revise plan** to send the original plan and the reviewer’s final feedback to the original agent. It responds with a complete replacement plan and does not implement it.
- **Review again** to start another independent review.

Set a dedicated default reviewer and tailor its review instructions in **Settings → General → Plan review**. If no dedicated reviewer is selected, reviews use the source thread’s model by default.

Plan reviews are advisory. They never overwrite a plan automatically, and earlier review threads remain available in thread history.
