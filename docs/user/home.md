# Home

Home is a single agent conversation that works across all your projects, and across linked
environments if you have them. Ask it to start work in a project, check on threads, run workflows,
or keep track of several efforts at once.

## Turning it on

Open **Home** at the top of the sidebar (or press `⌘⇧0`, `Ctrl+Shift+0` on Windows and Linux) and
choose **Enable Home**. Pick its model in **Settings → Home**; without one, Home uses the
environment's default model.

## What Home does for you

- Threads Home starts are watched: when one finishes or needs your approval, Home is told and can
  follow up. It can also watch threads and workflow runs you point it at.
- Home keeps durable notes in `notes.md`, which you can read and edit in **Settings → Home**.
  Notes survive **Start fresh**, which gives Home a new conversation.
- Home always starts work in a real project or a scratch folder, never in its own folder.

Home runs in full-access mode. Switch it to plan mode to make it read-only. Turning Home off stops
its current turn and clears what it watches.
