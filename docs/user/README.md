T3 Code controls the coding agents on your machine from a desktop app, a web app, and iOS and
Android apps. It works with the Codex, Claude, Cursor, Grok Build, OpenCode, and Antigravity
subscriptions you already have.

## Start here

- [Install T3 Code](./install.md): set up the machine where agents will work and connect a provider.
- [Working with threads](./thread-sidebar.md): start tasks and organize parallel work.
- [Permission modes](./permission-modes.md): choose when agents ask before acting.
- [Remote access](./remote-access.md): control T3 Code from your phone or another computer.

Questions or bugs? Ask in [Discord](https://discord.gg/jn4EGJjrvv) or open an issue on
[GitHub](https://github.com/pingdotgg/t3code/issues).
