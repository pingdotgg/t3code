# Generated Images

When Codex finishes generating an image, T3 Code shows the image filename below the **Image view**
entry in the thread work log. Select the filename to open the image in the right panel.

The same image reuses its existing panel tab. Selecting the filename again refreshes the preview,
which is useful if the file changed after the tab was opened. You can close or switch away from the
tab like any other right-panel surface.

Generated-image previews are available in the desktop and web clients, including when the client is
connected to a remote environment. The environment sends the image only when you open its preview.

This applies to completed images reported by Codex's image-generation tool. Image paths mentioned
only in an assistant message keep their normal file-link behavior. If a generated file was moved or
deleted after the activity completed, its preview can no longer be loaded.
