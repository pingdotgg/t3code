# Desktop Notifications

On Windows, the T3 Code desktop app shows a native notification when an agent finishes a turn
while the T3 Code window is not in focus. The notification is titled **Agent finished** and shows
the thread title, so you can tell which conversation is ready for you.

Notifications are silent and appear only while the window is unfocused; nothing is shown while you
are already looking at T3 Code. Threads that were already finished when the app connects do not
notify.

To turn these notifications off, use Windows' per-app notification settings under
**System Settings** → **Notifications**.
