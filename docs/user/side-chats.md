# Side chats

When a lesson raises a question, highlight the part you want to understand and choose **Ask in side chat**. The side chat opens beside the lesson with the highlight and its context. Choose **Done** when you are finished; the side chat leaves a note that the next lesson message can use. Sending a message in the lesson also finishes side chats you left open, unless one is still answering. Ask something in a finished side chat to reopen it. Side chats can nest, so follow a question as far as you need.

You can also highlight text inside an HTML embed, or use its corner button to ask about the whole embed.

## Settings

Open **Settings → Threads → Side chats** to choose the model for new side chats, change how they explain things, and attach skills. Skills are added when a side chat starts where its provider supports them; a few providers can only see the skill name.
