# Extensions

Extensions add VS Code views, panels, and commands to T3 Code. They come from
[Open VSX](https://open-vsx.org) and run on the environment, so every client connected to it
shares the same extensions.

## Install an extension

On web and desktop, open **Settings → Extensions**. Search Open VSX and choose **Install**.
To install something search does not show, choose **Add from link or .vsix** and paste an
Open VSX or VS Code Marketplace link, an ID such as `publisher.name`, or upload a `.vsix` file
up to 50 MB. A Marketplace link works only when the extension is also on Open VSX. Disable an extension to keep it installed without running it.

## Open an extension

Open the right panel in a thread and choose **Extension**, then pick the extension or one of
its views. You can also search **Open extension** in the command palette. Extension commands
also appear in the command palette, including commands from extensions without a panel.

After extensions open, they stay on that project until you reload the page. Reload also after
you install, disable, or remove an extension.

On mobile, **Settings → Extensions** shows what is installed on each environment. Install and
manage extensions from web or desktop.

## Microsoft-only extensions

Some extensions only work in Microsoft's VS Code. T3 Code marks them
**Microsoft-only: may not work**. You can install them, but they may fail to start or miss
features.
