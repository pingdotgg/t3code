# Panels

Terminals, files, diffs, browsers, devices, pull requests, and side chats are panels you can arrange
however you like around the chat. Your layout is saved on this device and stays the same as you move
between threads. Which tabs are open still belongs to each thread, so a thread with no terminal open
gives that space back to its neighbours.

The threads sidebar and the chat stay put. To put the sidebar on the right, go to **Settings** →
**Appearance** → **Sidebar position**.

## Move and split

Drag a tab to move it.

- Drop on a tab strip or the middle of a panel to add it as a tab there.
- Drop near the edge of a panel, or of the chat, to split it.
- Drop right at the outer side of a stack of panels to sit beside the whole stack.
- Drop at the outer edge of the window to run the full length of that side.

Press **Escape** to cancel a drag. Drag the line between two panels to resize them, or focus it and
use the arrow keys.

A new tab opens where you last put a tab of that kind. The **+** menu opens one in that tab strip's
group instead.

## Files and terminals

**Files** shows the project tree. Clicking a file opens it in its own tab, beside the tree the first
time, so the tree stays in view. Use **Show in Files** on a file tab to get back to the tree.

A terminal is a tab like any other. `terminal.toggle` puts its panel away and brings it back with its
sessions intact, so hiding a terminal never closes it.

## Hide and reset

The **View** button at the top right of the window lists the threads sidebar and your panels, so you
can show or hide one wherever you moved it, or hide them all. **Reset panel layout**, there or in
the command palette, restores the default arrangement; your open tabs stay open.

Each panel has its own maximize button on its tab strip. Double-clicking a tab does the same.

Windows narrower than 980 px don't have room for splits, so panels open as a sheet over the chat and
your layout returns when the window widens.
