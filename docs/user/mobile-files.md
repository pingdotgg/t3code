# Files on mobile

Open a thread's **Files** tab to browse its workspace and select a file. T3 Code previews common
images, Markdown, HTML, PDF, and SVG files.

On Android, selecting a binary glTF (`.glb`) file opens an interactive native 3D preview. Drag with
one finger to orbit, pinch to zoom, and drag with two fingers to pan. Animated models play up to 10
seconds of their first animation once and then hold the final pose; tap the model to play it again.
Use **Refresh** from the file actions menu after the file changes.

On iPhone and iPad, `.glb` files show a note that 3D previews are Android-only. GLB previews are
limited to 100 MB on mobile. The model stays in its workspace; T3 Code loads it through the same
environment connection used by the rest of the Files tab.
