# Referral points

T3 Code referral points belong to your T3 account. Sign in with the same account to see the same
balance on web, desktop, or mobile, even when you use a different machine.

Open your account menu and choose **Referrals** to find your referral link and code. On mobile, open
**Settings → Account → Referrals**.

Referral links open the hosted T3 Code app. If the recipient is signed out, T3 Code saves the code
and opens sign-in. It claims the referral after that account signs in. The shared message states
that the referrer receives the 67 points; it does not promise points to the recipient.

You earn 67 points when someone:

1. Opens your referral link or enters your code while signed in.
2. Claims the referral before linking any T3 Code environment to their account.
3. Links their first environment.

A referral appears as pending after the code is claimed. It becomes successful and adds 67 points
when the referred account links its first environment. A code can be claimed only once per account,
and you cannot claim your own code.
