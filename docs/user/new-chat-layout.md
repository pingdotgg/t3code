# Panel layout for new chats

A new chat opens as a chat column on its own. If you always want the files panel or a terminal
next to it, T3 Code can open them for you on web and desktop.

1. Open **Settings** and select **General**.
2. Turn on **Open files panel in new chats**, **Open terminal in new chats**, or both.

Both are off by default. When one is on, it applies wherever a new chat in a project begins — the
new chat button, the command palette, a keyboard shortcut, checking out a pull request, or sending
a plan off to be implemented in its own chat.

These settings only decide how a chat starts. Closing the files panel or the terminal applies to
that chat alone, and the next new chat still opens with the layout you asked for. Turning a setting
on or off leaves the chats you already have as they are.

The preference is stored on the client you set it on, so each computer or browser you use T3 Code
from keeps its own layout for new chats.
