# Follow the system theme

On supported Linux desktop installations, T3 Code can use the colors from your active system theme. Omarchy is currently supported.

Open **Settings → Appearance**, then choose **System Theme** from the theme library. T3 Code updates automatically when the active system theme changes.

This choice is hidden when the desktop cannot provide a system color palette, including web, mobile, macOS, Windows, and unsupported Linux desktops. If a previously selected palette becomes unavailable, T3 Code uses its standard colors until the palette returns.
