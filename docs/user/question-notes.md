# Notes on question answers

When an agent asks you to pick from options, you can pick and also add a note, such as "Option B, but keep the old endpoint for one release". The agent gets the option you picked and your note together.

- **Web and desktop**: Type the note in the composer, then pick the option. Picking a single-choice option sends the answer, so type first. For a multiple-choice question, or one you went back to, the note can come after the pick.
- **Mobile**: Pick the option, type in the answer field, then tap **Submit answers**.

## Behavior

- **One note per question**: A note covers everything you picked for that question.
- **Nothing picked**: Typed text with no option picked is your own answer, as before. Tap a picked option again to clear it.
- **Which agents**: Claude, Codex and Grok take notes, as do agents whose questions come with an "Other" text field. Where an agent can't take one, typing replaces the pick as before, and the field asks for your own answer instead of a note. Requires an up-to-date server.
