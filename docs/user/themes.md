# Themes

Importing a VS Code color theme (`*-color-theme.json`) colors the app chrome and the editor highlighting used in diffs, file preview, chat code blocks, and search. Built-in palettes (Grove, Ocean, Ember, Iris, T3 Chat) keep Pierre highlighting until you attach a VS Code theme.

You can inspect and edit that highlighting as `tokenColors` JSON in the theme editor, or in a downloaded theme file. Changing canvas, accent, or other chrome colors does not rewrite the highlighting.
