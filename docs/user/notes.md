# Notes

Notes shows the Markdown notes in a folder on the machine that runs your T3
Code server, such as an Obsidian vault. It is read-only: browse, search, and
read notes from web or desktop, including when you connect remotely.

To turn it on, open **Settings → General → Notes** and set **Notes vault
folder** to the vault's path on that machine, such as `~/Obsidian/Vault`. Then
choose **Notes** in the sidebar.

Search matches note names, folders, and note text. The list shows the 500 most
recently changed notes, so search to find older ones. Hidden folders such as
`.obsidian` and `.trash` are skipped, and notes larger than 1 MB cannot be
opened or searched by content.
