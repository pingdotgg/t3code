# Notes

Notes shows the Markdown notes in a folder on the machine that runs your T3
Code server, such as an Obsidian vault. Browse, search, create, and edit notes
from web or desktop, including when you connect remotely.

To turn it on, choose **Notes** in the sidebar and pick the folder with
**Choose folder** on desktop, or set **Settings → General → Notes → Notes vault
folder** to the vault's path on that machine, such as `~/Obsidian/Vault`.

Use **+** to create a note; type a name such as `Ideas` or `Projects/Plan`, and
the `.md` file is created in the vault. The pencil edits a note, and
<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>S</kbd> saves it. **Add to chat** attaches
the note to the open thread's composer so the agent gets it as context.

Search matches note names, folders, and note text. The list shows the 500 most
recently changed notes, so search to find older ones. Hidden folders such as
`.obsidian` and `.trash` are skipped, and notes larger than 1 MB cannot be
opened or searched by content.
