# Thread Labels

Use a lightweight label to keep related threads together. T3 Code supports **Bug**, **Feature**, **Review**, and **New Build**.

To label a thread, open its context menu and choose **Add label**. Choose a different label to replace the current one, or choose **Clear label** to remove it. Labels sync with the environment, so the same thread keeps its label when you open it from the web app, desktop app, or mobile app.

When AI generates a new thread title, it also chooses a label when the thread has not been labeled manually. Manual labels are always preserved.

Use the tag filter in the thread list to show only threads with a selected label. Choosing **All labels** returns the complete list.
