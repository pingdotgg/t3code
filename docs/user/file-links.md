# File links

File references in chat appear as clickable chips. By default, each chip shows the file name and
adds parent folders only when two links would otherwise look the same. Hover a chip to see its full
path.

Enable **Settings → General → File chip paths** to show a compact path directly in every chip.
Files inside the project use `./`. For projects under your home directory, other home files use
`~/`; files outside both keep their absolute path. Line and column numbers stay attached to the
path.
