The Enriched Markdown tarball comes from the [`fork/t3-mobile` branch](https://github.com/juliusmarminge/enriched-markdown/tree/fork/t3-mobile). Its `t3-fork.json` records the exact source commit and upstream base. It adds native file/skill link recognition, clipboard metadata, parsed asset manifests, signed image source resolution, and React media slots to upstream's pills and menus.

To replace it, commit the fork changes, run `yarn install --immutable` and `yarn workspace react-native-enriched-markdown prepare` in the fork checkout, then `node scripts/pack-t3.mjs /path/to/t3code/apps/mobile/deps`. Bump the fork package version for each replacement, update `apps/mobile/package.json`, and run `vp i` to update the lockfile. Native clients need rebuilding when this dependency changes.
