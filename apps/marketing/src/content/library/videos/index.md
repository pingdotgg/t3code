T3 Code is the subject of this collection of Theo Browne's launch, product, and workflow videos. Each page explains the argument, follows the video's main sections, and connects the discussion to current feature guides. Start with the alpha launch, then choose a product tour or the workflow problem you want to understand.

## Start with the launch and product walkthrough

1. [It's finally here: the T3 Code alpha launch](/learn/videos/its-finally-here) explains why Theo and Julius build an open source interface around coding agents. It introduces threads, worktrees, and using an existing provider rather than buying inference from T3 Code.
2. [T3 Code broke me](/learn/videos/t3-code-broke-me) gives a wider product tour. It connects multiple providers, remote hosts, an inbox-style sidebar, visual outputs, and pull request review to Theo's daily workflow.

These two videos provide a starting point for the rest. The launch explains the motivation. The later tour shows how that motivation develops into a broader place to manage work.

## Understand the ideas and working methods

3. [My last video about AI harnesses](/learn/videos/my-last-video-about-harnesses) separates the model, the runtime that gives it tools, and the interface a developer uses. It also explains why a shared interface does not make every provider's configuration identical.
4. [Agents sucked at UI (until today)](/learn/videos/agents-sucked-at-ui) follows a design experiment with screenshots and repeated model critiques. It shows both the value of visual feedback and the uncertainty of numerical design scores.
5. [You're using AI agents wrong](/learn/videos/using-ai-agents-wrong) works through real tasks and reviews. Its focus is reducing friction in investigation, explanation, testing, and delivery.
6. [How I code with AI changed a lot](/learn/videos/how-i-code-with-ai-changed) offers a different workload: a large solo project with many sequential tasks. It emphasizes clear conversations, useful project guidance, and fresh context when the concern changes.

The workflows vary because the work varies. Read the examples as decisions you can test in your own project, rather than a fixed formula for thread counts or model choices.

## Explore subscriptions, input, and remote work

7. [I need you guys to trust me on this (sorry Anthropic)](/learn/videos/trust-me-on-this) records the Claude Code integration announcement and Theo's reasoning about using the provider's runtime. Its policy discussion is historical context.
8. [How I code without typing](/learn/videos/code-without-typing) explains changes Theo makes when typing and app switching become difficult. Dictation and broader task requests help him reduce manual steps.
9. [I'm done with terminals](/learn/videos/done-with-terminals) describes why he moves task organization into a graphical interface. Images, thread navigation, and remote continuity are central examples.
10. [If you have a Claude sub, watch this](/learn/videos/if-you-have-a-claude-sub) covers an advanced personal setup and a wider delegation workflow. The summary distinguishes current T3 Code features from account, pricing, and proxy assumptions in the recording.

## Use feature guides alongside the videos

Use the chapters to find a discussion, then follow the linked feature page before configuring the product. A video can explain why a feature exists even after its settings or limitations change. The summaries identify those changes where the repository documents a different behavior.
