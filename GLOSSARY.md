# Glossary

Canonical terms for the toolboxmd fork. Names follow the Lightbringer series
by Brent Weeks, the source of the company name.

| Term      | Meaning                                                                                                                                                            | Avoid                                   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------- |
| Luxin     | The company; also the work agents produce (code, PRs).                                                                                                             |                                         |
| Chromeria | This app: the gateway where the user directs every agent across harnesses, with more interfaces (such as the OpenBot mode) over time. Built from the T3 Code fork. | T3 Code Fork, Bridge                    |
| Drafter   | An agent working for the user on one harness and model.                                                                                                            | bot (reserved for OpenBot's named Bots) |
| Prism     | Planned product name for Model Router: splits work across models and balances capacity. Not renamed yet.                                                           |                                         |
| Toolbox   | Planned name for the user's own future harness.                                                                                                                    |                                         |
| T3 Code   | The upstream project this fork tracks (`pingdotgg/t3code`).                                                                                                        |                                         |
