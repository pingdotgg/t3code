# Files in the Conn monorepo that a part of the Conn Server follows. For each part,
# tools/bump-report.mjs prints the upstream commits (subject lines) that touched its files
# between the old and the new pin, and a diff stat for the provider adapters.
#
# A line `[<part>]` starts a part: a crate or a file of this repository. Each other line is one
# Git pathspec in the Conn monorepo (`:(glob)` allowed). Test files are left out of the
# commit lists. Add a pathspec when a part starts to follow a file.
#
# This map is not complete on purpose: upstream adds files every day, so a check that every
# upstream file is mapped would be red every night. The report lists new upstream files that
# no part follows, as a short list to read.
