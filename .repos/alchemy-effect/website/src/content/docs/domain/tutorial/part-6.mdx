Build a browser app with [foldkit](https://foldkit.dev): sign in, open your account, deposit, and see the balance change as it happens.

## Install

```sh
bun add foldkit @effect/platform-browser
bun add -d vite @foldkit/vite-plugin
```

## Add the browser's types

The app runs in a browser. Add `"DOM"` to `lib` in your `tsconfig.json`, so `document` and `location` type-check:

```json
{
  "compilerOptions": {
    "lib": ["ESNext", "DOM"]
  }
}
```

## Configure Vite

```typescript
// vite.config.ts
import { foldkit } from "@foldkit/vite-plugin";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [foldkit()],
  optimizeDeps: {
    entries: ["src/web/entry.ts"],
    include: ["effect", "effect/Function", "effect/http", "@effect/platform-browser"],
  },
});
```

The foldkit plugin builds the app. `include` pre-bundles the Effect modules foldkit imports, so the browser loads one copy of Effect.

## Describe the app's state

```typescript
// src/web/Bank.ts
import type * as Domain from "@alchemy.run/domain";
import * as Schema from "effect/Schema";
import { defineMessageUnion } from "foldkit/message";
import { AccountId } from "../Account.id.ts";
import { CustomerId } from "../Customer.id.ts";

// The bank client this app runs on, provided when the app starts.
type Bank = Domain.Api.ClientKey<"BankApi">;

export const Flags = Schema.Struct({ customerId: CustomerId });
export type Flags = typeof Flags.Type;

export const Model = Schema.Struct({
  customerId: CustomerId,
  accountId: AccountId,
  // `null` until the account is open.
  balance: Schema.NullOr(Schema.Number),
  error: Schema.NullOr(Schema.String),
});
export type Model = typeof Model.Type;

export const Message = defineMessageUnion({
  ClickedOpen: {},
  ClickedDeposit: {},
  Succeeded: {},
  Failed: { reason: Schema.String },
  GotBalance: { balance: Schema.NullOr(Schema.Number) },
});
export type Message = typeof Message.Type;
```

`Flags` is what the app starts with, `Model` is what it shows, and `Message` is everything that can happen. The balance is `null` until the account is open.

## Send domain commands

```diff lang="typescript"
// src/web/Bank.ts
import type * as Domain from "@alchemy.run/domain";
+import * as Effect from "effect/Effect";
import * as Schema from "effect/Schema";
+import { Command } from "foldkit";
import { defineMessageUnion } from "foldkit/message";
import { AccountId } from "../Account.id.ts";
+import { BankApi } from "../BankApi.api.ts";
import { CustomerId } from "../Customer.id.ts";
// ...
});
export type Message = typeof Message.Type;
+
+export const Register = Command.define("Register", {
+  args: { customerId: CustomerId },
+  messages: [Message.Succeeded, Message.Failed],
+  execute: ({ customerId }) =>
+    Effect.gen(function* () {
+      const bank = yield* BankApi.Client;
+      yield* bank.RegisterCustomer(customerId, { name: customerId });
+      return Message.Succeeded();
+    }).pipe(Effect.catch((error) => Effect.succeed(Message.Failed({ reason: error._tag })))),
+});
+
+export const Deposit = Command.define("Deposit", {
+  args: { accountId: AccountId, amount: Schema.Number },
+  messages: [Message.Succeeded, Message.Failed],
+  execute: ({ accountId, amount }) =>
+    Effect.gen(function* () {
+      const bank = yield* BankApi.Client;
+      yield* bank.DepositMoney(accountId, { amount });
+      return Message.Succeeded();
+    }).pipe(Effect.catch((error) => Effect.succeed(Message.Failed({ reason: error._tag })))),
+});
```

A foldkit command runs a domain command through the bank client and turns the outcome into a message. A rejection becomes `Failed` with its tag.

## Start the app

```typescript
// src/web/entry.ts
import * as Domain from "@alchemy.run/domain";
import * as Effect from "effect/Effect";
import * as FetchHttpClient from "effect/http/FetchHttpClient";
import * as HttpClient from "effect/http/HttpClient";
import * as HttpClientRequest from "effect/http/HttpClientRequest";
import * as Layer from "effect/Layer";
import * as Socket from "effect/socket/Socket";
import { Runtime } from "foldkit";
import { BankApi } from "../BankApi.api.ts";
import { CustomerId } from "../Customer.id.ts";
import { Flags, init, Model, subscriptions, update, view } from "./Bank.ts";

// A stand-in for a login page: `?customer=c-2` picks who you are.
const customerId = CustomerId.make(new URLSearchParams(location.search).get("customer") ?? "c-1");

// Sign in, so the browser holds the session cookie for every call and watch.
const signIn = Effect.gen(function* () {
  const client = HttpClient.filterStatusOk(yield* HttpClient.HttpClient);
  yield* client.execute(
    HttpClientRequest.post("/api/session").pipe(HttpClientRequest.bodyJsonUnsafe({ customerId })),
  );
});

const BankConnection = Layer.unwrap(
  signIn.pipe(
    Effect.orDie,
    Effect.as(
      BankApi.layerClient.pipe(
        Layer.provide(Domain.protocolWebSocket(`${location.origin}/api`)),
        Layer.provide(Socket.layerWebSocketConstructorGlobal),
      ),
    ),
  ),
).pipe(Layer.provide(FetchHttpClient.layer));

Runtime.run(
  Runtime.makeApplication({
    Model,
    Flags,
    init,
    update,
    view,
    subscriptions,
    resources: BankConnection,
    container: document.getElementById("root"),
  }),
  { flags: Effect.succeed({ customerId }) },
);
```

The app signs in first, then connects to the Api on its own origin. `Domain.protocolWebSocket` sends commands over HTTP and opens a WebSocket for each watch.

## Serve the app and the Api from one origin

```typescript
// src/web/worker.ts
interface Fetcher {
  fetch(request: Request): Promise<Response>;
}

// Serve the app, and forward /api to the bank: one origin, so the session cookie is first-party.
export default {
  fetch(request: Request, env: { readonly ASSETS: Fetcher; readonly BANK: Fetcher }) {
    const { pathname } = new URL(request.url);
    return pathname.startsWith("/api") ? env.BANK.fetch(request) : env.ASSETS.fetch(request);
  },
};
```

The app's Worker serves the built page and forwards `/api` to the bank. Sharing one origin keeps the session cookie first-party, so browsers send it.
