# cloudflare-foldkit

A [Foldkit](https://foldkit.dev) counter app deployed to Cloudflare with
`Cloudflare.Website.Foldkit`.

```sh
bun alchemy deploy   # build and deploy
bun alchemy dev      # local dev with Vite HMR
bun alchemy destroy  # tear down
```

See the [Foldkit guide](https://alchemy.run/cloudflare/frontend/foldkit) for a
walkthrough.
