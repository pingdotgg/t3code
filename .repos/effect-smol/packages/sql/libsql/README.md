# @effect/sql-libsql

An Effect SQL client for [libSQL](https://turso.tech/libsql), built on the [`@libsql/client`](https://docs.turso.tech/sdk/ts) library.

## Installation

```sh
npm install effect@rc @effect/sql-libsql@rc
```
