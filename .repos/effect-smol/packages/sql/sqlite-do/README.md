# @effect/sql-sqlite-do

An Effect SQL client for the SQLite storage in [Cloudflare Durable Objects](https://developers.cloudflare.com/durable-objects/).

## Installation

```sh
npm install effect@rc @effect/sql-sqlite-do@rc
```
