# @effect/sql-pglite

An Effect SQL client for [PGlite](https://pglite.dev), a WASM build of PostgreSQL that runs in the browser, Node.js, and Bun.

## Installation

```sh
npm install effect@rc @effect/sql-pglite@rc
```
