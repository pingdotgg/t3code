# Local server stream consumer

Build with `node ../../bin/t3-extension.mjs build .`, then check `.t3-extension`.
Install into a disposable runtime with the `t3.browser/read-local-servers` grant
and a project grant. Subscribe to `example.browser-local-servers/read` through
the public SDK API facade; this package relays the host's typed stream.

Snapshots replace the previous list. URLs name loopback on the server
environment, which may differ from the viewing device. This API does not
open a page or provide a browser engine. `truncated` means candidates were
omitted by the bounded projection. Cancel the stream when it is no longer needed.
