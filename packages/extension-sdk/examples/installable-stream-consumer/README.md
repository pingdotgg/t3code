# Independent stream consumer

Install installable-stream-provider first, then this separate format-3 package with the same project grant. Open Mirrored counter. Its client consumes this package's own namespaced stream; its server consumes the provider's stream through a declared versioned plugin dependency. Host scope, grants and read-only ancestry apply through both workers.

This example demonstrates worker-to-worker streaming and failure states. It does not implement a Terminal or Browser panel, durable state, or native engine attachment. See the provider README for lifecycle and test expectations.
