Exploratory QA, with evidence

Let an agent explore your site. Keep the proof.

Exploro is an open-source app for manual QA engineers. Give it a website and a testing goal. An agent tests the site in a real browser while you watch, take over when you want, and get a report with a verdict and screenshots for every scenario.

How it works

You stay the QA engineer. The agent does the clicking, and Exploro keeps a record of everything it saw.

Name the site and goal

Paste a URL and describe what to test, in plain words. Add test credentials if the flow needs them.

The agent explores

It opens the site in Exploro's built-in browser and works through the flow like a careful tester, scenario by scenario.

Watch or take over

The browser runs beside the chat. Step in at any point, and approve anything risky before it happens.

Keep the evidence

Each run ends with a report: a verdict per scenario, screenshots, and the console and network errors behind them.

Built for testers, not developers

Exploro is a QA-focused fork of T3 Code. The developer tools are out of the way; the QA workflow is up front.

A real browser

Tests run in a real Chromium browser with screenshots, console, and network capture, not a simulated page.

Report only

The agent tests what is deployed. It never edits your code and treats text on the page as data, not instructions.

Asks before it acts

Payments, deletions, sending messages, and other irreversible steps wait for your approval.

Your agent, your account

Exploro drives the coding agents you are already signed in to. It does not resell tokens.

Evidence on disk

Runs are saved locally as Markdown and a self-contained HTML report you can attach to a bug ticket.

Open source

MIT licensed and built in the open. Read the code, file an issue, or fork it.

Verdicts you can trust

A wrong PASS is the worst result a tester can give. Every scenario ends with one of five verdicts, and a verdict without a screenshot is stored as inconclusive, whatever the agent claimed.

PASS

The expected behaviour was seen and captured.

FAIL

The site did something different from what was expected, with the screenshot to show it.

BLOCKED

The agent could not continue: a login, a missing approval, or a broken step earlier in the flow.

INCONCLUSIVE

There is not enough evidence to say either way.

SKIPPED

Out of scope for this run, or you chose to leave it.

Works with the agent you already use

If an agent is set up on your computer, Exploro can run your tests with it.

Download Exploro

Desktop builds for Windows and Linux (64-bit). Exploro is in beta: builds are not code-signed yet.

Windows

Windows 10 and 11, x64
Get the installer (.exe)

Windows may show a SmartScreen warning because the build is unsigned. Choose More info, then Run anyway.

Linux

AppImage, x64 (Ubuntu 22.04+, Fedora, Debian…)
Get the AppImage

Make the file executable, then run it:

chmod +x ./*.AppImage
./*.AppImage

All versions and release notes are on the releases page.

Build from source

Prefer to run it yourself? Exploro uses the Vite+ toolchain. See EXPLORO.md for the full setup. 

git clone https://github.com/imavinashsingh/exploro.git
cd exploro
vp i
vp run dev --home-dir ~/.exploro/dev
