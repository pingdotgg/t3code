# Contributing

Hyakki is built for the Ryoku desktop and maintained by a small team. Bug fixes are the most welcome
contribution; for features, open an issue first so we can agree on the shape before you build it.

- Search [issues](https://github.com/neur0map/hyakki/issues) before you report a bug, and include
  steps to reproduce, what you expected, and what happened.
- Keep pull requests small and focused on one change.
- Build and test with the [development runbook](./docs/operations/00_development.md). Run `vp check`
  and the tests for the packages you touched before you push.
- Fixes from upstream T3 Code arrive through the daily Upstream Fixes pull request. Do not port an
  upstream commit by hand unless that pull request reported that it did not apply.

By contributing, you agree that your work is released under the [MIT License](./LICENSE).
