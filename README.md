# T3 Code, with modular panels

The surfaces are now modular. Drag any panel anywhere, split it, stack it, maximize it.

Using the nightly from the AUR on Arch Linux? Download [the install script](https://raw.githubusercontent.com/faetalize/t3code/feature/modular-panel-system/install_on_nightly_arch.sh) and run it:

```bash
bash install_on_nightly_arch.sh
```

AUR updates wipe this feature away, so run the script again after every update. To remove it, reinstall `t3code-nightly-bin`.
